我的第一次 Agent 实验

来源：我的博客《我的第一次 Agent 实验》，整理为 Wiki 长期笔记。

第一次使用 Agent 做网站时，我学会的最重要的一件事是：不要只说“做一个好看的个人网站”。

可执行需求的结构

用户是谁 + 做什么 + 有哪些内容 + 有什么约束 + 怎样算完成

例如：用户是江苏警官学院数据警务技术专业的学生；页面要展示姓名、学校、专业、简介、兴趣和邮箱；只使用 HTML 和 CSS；双击 index.html 能打开就算完成。

要点

  • 需求越可验证，Agent 越少自由发挥；
  • 完成标准必须可以实际检查，不能接受“看起来差不多”。

这次实验开启了整个网站的迭代过程，它遵循的流程记录在 Agent Loop 迭代循环；而每一步改动的底气来自 Git 是 Agent 开发的安全绳。
