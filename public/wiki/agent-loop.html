Agent Loop 迭代循环

这个网站不是一次性设计完的，而是按一个固定循环不断长出来的：

提出真实需求 → Agent 实现 → 运行验证 → Git 保存 → 发布 → 继续增加功能

为什么需要循环

  • 一次只加一个功能，出错容易定位；
  • 每个循环都有可运行、可验证的产出；
  • Git 保存检查点，发布后再开始下一轮，始终拥有一个可用版本。

与本网站的对应

每一个课程 Step 都是一次循环：最小首页、Git 与部署、多页面导航、Markdown 博客、RSS、论文收集、Wiki、状态面板。第一次循环的记录见 我的第一次 Agent 实验。
