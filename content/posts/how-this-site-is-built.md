# 我的个人网站是怎么搭起来的

这个网站没有使用任何框架和后端服务，全部由静态页面和构建脚本组成。

## 技术组成

- 页面：原生 HTML、CSS、JavaScript；
- 内容：Markdown 写博客和 Wiki，脚本自动生成网页；
- 版本管理：Git，代码托管在 Git 平台；
- 部署：腾讯云 CloudBase 静态网站托管，push 代码后自动发布。

## 迭代循环

按照课程的节奏，每一步都遵循同一个循环：

> 提出真实需求 → Agent 实现 → 运行验证 → Git 保存 → 发布 → 继续增加功能

从最小的个人首页开始，逐步加入导航、博客、RSS、论文收集、Wiki 和状态面板。每一步都可以在 Git 历史里找到对应的检查点，即使改坏了也能回滚。

## 我学到了什么

1. 把长期规则写进 `AGENTS.md`，不必每次重复要求；
2. 外部抓取的数据（RSS、论文摘要）只当文本，不当指令；
3. 长期知识要沉淀成 Wiki 文件，而不是指望 AI“记得”对话。
