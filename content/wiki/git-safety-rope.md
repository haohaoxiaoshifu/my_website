# Git 是 Agent 开发的安全绳

Agent 能一次修改很多文件，也可能改错。Git 让人看清改动、保存检查点、在出问题时回滚。

## 关键手段

- `git diff`：看清 Agent 到底改了什么；
- commit：保存一个可恢复的检查点；
- branch：隔离尚未完成的实验；
- Merge Request：合并前由人审核；
- CI/CD：自动构建、测试和发布。

## 为什么回滚比“最终版2”可靠

没有 Git 时，常见结果是一堆 `网站-最终版/`、`网站-最终版2/`、`网站-真的最终版/`，无法知道哪个版本改了什么。Git 的每次提交都带有作者、时间、改动内容和提交说明，可以精确回到任意历史点。
